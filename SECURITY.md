# Sicurezza / Security

*Italiano prima, English below.*

## Segnalare una vulnerabilita'
Scrivi a **security@infinitek.it**. Non aprire issue pubbliche per
vulnerabilita'. Indica: prodotto e versione (tag `api-v*` o immagine), come
riprodurre, impatto.

Tempi: conferma di ricezione entro 3 giorni lavorativi; valutazione entro 10;
correzione secondo gravita' (critica: il prima possibile, con avviso agli
utenti); pubblicazione dell'avviso nel changelog (sezione "Sicurezza") e nelle
note di rilascio quando la correzione e' disponibile.

Chi segnala in buona fede, senza accedere a dati non propri e senza
interrompere il servizio, non subira' azioni legali da parte nostra (safe
harbor).

Versioni supportate: l'ultimo tag `api-v*` di questo repository. Questo
progetto e' una versione modificata di rustdesk-api (MIT) di lejianwen.

## Reporting a vulnerability
Email **security@infinitek.it**. Please do not file public issues for
vulnerabilities. Include product and version, reproduction steps and impact.
We acknowledge within 3 business days, triage within 10, fix by severity and
publish an advisory in the changelog. Good-faith researchers are safe from
legal action. Supported versions: the latest `api-v*` tag.
